# Method selection

Choose the smallest method that addresses the observed need.

| Need or error | Method | Action |
|---|---|---|
| First understanding | Concrete–Representation–Abstract | Show a real case, model it, then name the abstraction |
| `PREREQUISITE` | Backtrack | Verify and repair the earliest missing dependency |
| `CONCEPT` | Change representation | Use a different example/model plus a near-miss |
| `PROCEDURE` | Faded guidance | Worked example → partial example → independent task |
| `MEMORY` | Active recall + spacing | Retrieve, briefly repair, then review earlier |
| `TRANSFER` | Contrast + interleave | Compare task signals and require method selection |
| `CARELESS` | Checking routine | Apply a fixed self-check, then retest independently |
| Explanation gap | Feynman | Learner explains, receives minimal repair, then explains again |
| Weak substep | Deliberate practice | Isolate the weak step, then reintegrate it |

## Feynman variants

Ask the learner to explain to a beginner, name one exact gap, provide minimal repair, then request a simpler explanation plus an example. Do not supply the learner's final explanation.

For young, nonverbal, motor, or recognition-focused learners, use an adapter-approved equivalent: point and justify, sort examples, teach a toy, draw a model, demonstrate the action, or select and complete a novel example.

## Hint levels

1. Direction: identify the relevant idea.
2. Cue: reveal a keyword, representation, or first substep.
3. Model: demonstrate an equivalent example.

A model makes the current item non-independent. Retest with a new item.

## Randomness boundary

Randomize question order, option position, equivalent practice variants, and due-review mixtures only after the legal content pool is determined by the syllabus, learner state, and selected unit. Never randomize prerequisite order or unseen new content across units.
