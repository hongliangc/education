# 视频影院播放与导航失效

- id: `2026-07-18-theater-playback-navigation`
- status: done
- commit: this commit

## 现象与复现
- 在某个剧集的“全部”列表打开任意视频后，无法返回上一层。
- 选择指定剧集后无法打开播放。
- 播放时点击“下一集”无法播放下一集。

## 根因
- 播放不同剧集时复用了同一个 `VideoPlayer` 组件实例，上一集的媒体元素、清晰度、播放进度和控件状态会残留并污染新一集。
- 视频源加载期间，全屏状态遮罩覆盖顶部返回按钮，且遮罩只在错误态显示“返回片库”，导致准备中无法退出。
- 播放成功后，顶部返回按钮又随播放控件自动隐藏，造成播放中没有可见的返回入口。
- 游戏布局的 `z-10` 创建了独立堆叠上下文，使播放器的 `z-50` 无法越过同级 HUD 的 `z-30`；HUD 实际遮挡播放器返回、选集和下一集交互。

## 修复
- 按视频 id 重建播放器实例，切集和“下一集”都从干净的媒体状态开始。
- 加载与错误遮罩始终提供“返回片库”按钮。
- 播放中的顶部返回按钮保持可见，不再随底部播放控件淡出。
- 使用 React portal 将播放器挂到 `document.body`，绕开游戏内容容器的堆叠上下文，让播放器正常覆盖 HUD。

## 回归测试
- 检查影院页面按当前视频 id 挂载播放器，加载态和播放态都保留返回入口。
- 检查播放器通过 portal 脱离游戏布局的堆叠上下文。
