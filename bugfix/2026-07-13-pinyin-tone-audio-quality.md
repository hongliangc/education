# 拼音四声音频体验差

- id: `2026-07-13-pinyin-tone-audio-quality`
- status: done
- commit: this commit

## 现象与复现
- 拼音学习中的四声音频听感不自然、声调辨识度和儿童学习体验较差。
- 进入拼音乐园，依次播放同一韵母的四个声调并比较。
- 四声卡片没有标注与读音匹配的示例字，且清单统一使用“妈、麻、马、骂”作为所有拼音的占位字。

## 根因
- 当前拼音点读使用通用腾讯云 TTS 运行时合成，而不是经过教研验收的固定示范音。
- 默认音色 `601009` 是聊天类大模型音色，并非拼音教学音色；孤立音素和夸张四声不是它的目标场景。
- 服务端只请求 16kHz 音频，客户端再用 `playbackRate = 0.8` 拉慢，短音节更容易产生拖曳和失真。
- `i/u/ü` 使用 `i/u/v` 孤立音素和汉字占位组合来引导模型；腾讯文档没有提供完整的孤立韵母音素清单，模型行为不够可验证。
- 当前未开启字幕音素返回，无法核对服务最终采用的拼音音素。
- 四声音频清单只保存了音素，没有保存该音素对应的教学汉字；`toneFallback()` 因而对所有拼音返回同一组“妈、麻、马、骂”。
- 声母也被套用了韵母四声模板，并通过 `ba/pa/...` 临时组合，混淆了“声母本音”和“完整音节声调”。
- 进一步试听发现 AWS Polly 合成孤立清辅音时，部分声母片段极短或近似无声，不适合作为儿童点读示范音。

## 修复
- 声母不展示四声；基础点读改用小学拼音教学中清晰可听的示范读音，如 `b · bo · 玻`、`p · po · 坡`。
- 为韵母和整体认读音节建立常用声调例字表；卡片同时展示韵母声调、完整音节、对应汉字和词语，例如 `uī · guī · 龟 · 乌龟`。
- 音频清单直接复用声调例字的完整音节和汉字，移除全局“妈、麻、马、骂”占位逻辑，确保画面、音素和发音来源一致。
- 对 `ri/yue/er` 等缺少低龄常用字的声调不使用生僻字硬凑，只展示有效例字。
- 使用 AWS Polly 东京区 `ap-northeast-1`、`Zhiyu/neural`、24kHz 重新生成 63 个基础读音和 149 个有效声调例字，共 212 个 MP3；清理 103 个旧的无效文件。
- 23 个声母按 `bo/po/mo/fo`、`de/te/ne/le`、`ge/ke/he`、`ji/qi/xi`、`zhi/chi/shi/ri`、`zi/ci/si`、`yi/wu` 重新生成；界面同步标注声母、示范拼音和示范字。
- 新增可重复执行的清单导出与无第三方依赖生成脚本，AWS 密钥只在离线生成进程使用。

## 回归测试
- 自动检查声母没有四声、声母使用已确认的教学示范读音、声调清单音素与示例字一致，以及 `ui` 四个代表例字的完整映射。
- 自动检查 23 个声母教学音素映射和音频最小长度，防止再次出现近似无声的极短文件。
- 自动检查 212 项清单路径唯一、文件存在且非空、静态播放接线和 Polly 配置。
- 使用 `pinyin-pro` 逐项复核 149 个示例字的拼音和声调，未发现映射不一致。
