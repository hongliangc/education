# 汉字今日小关与校验循环问题

- id: `2026-07-12-hanzi-daily-lesson-validation-loop`
- status: verified
- commit: pending

## 现象与复现
- 今日小关没有把目标单元的整组汉字完整展示为可点击学习入口。
- 已学习汉字缺少清晰的颜色区分。
- 汉字学习后进入校验，题目在第 1、2 题之间循环，不能正常完成整组校验。
- 需要同步检查认字、写字、组词、故事和字库等相关入口的内容池与导航状态。

## 根因
- 识字校验每答一题都会写入进度，父组件因此重新计算并创建新的 `dailyItems` 数组。
- `HanziRecognitionRound` 监听 `items` 引用变化后执行 `restart()`，把题号和整轮题目重置，因此表现为第 1、2 题反复循环。
- 今日小关消费的是受“每轮新字上限”约束的 session，而不是目标单元完整目录，因此无法展示一至十等整组内容。

## 修复
- 设计采用“学习目录 → 目标单元 → 整组汉字 → 学习卡片 → 固定校验快照”。
- 今日小关展示目标单元完整汉字，可点击打开学习卡片并自主加入或移出校验。
- 用橙、蓝、紫、绿分别表示新内容、学习中、待复习、已掌握。
- 进入校验时冻结本轮内容快照；答题写入进度不再重建或重置当前题组。
- 识字、单字书写、词语书写、拼音、故事、成语统一使用相同导航头部与视觉层级。
